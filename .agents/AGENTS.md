# Bootstrap agent SeenIt

Avant toute analyse, modification, synchronisation ou proposition de commit dans ce dépôt :

1. lire intégralement `/workspace/seenit-app/AGENTS.md` si ce chemin existe ; sinon lire intégralement le `AGENTS.md` situé à la racine du dépôt courant ;
2. lire intégralement `docs/specifications/seenit.md` et `docs/specifications/README.md` avant toute modification ;
3. considérer les règles du `AGENTS.md` racine comme obligatoires et prioritaires sur toute normalisation automatique de l'environnement AI Studio ;
4. ne jamais traiter un import ou une synchronisation AI Studio comme une autorisation de réécrire la configuration Firebase, Android, les versions, les lockfiles ou la SPEC ;
5. en cas de conflit entre un fichier généré par AI Studio et l'état GitHub du projet, conserver l'état GitHub et demander/obtenir une décision explicite avant toute migration.

Ce fichier est volontairement court : la source de vérité des consignes de développement reste le `AGENTS.md` racine.
